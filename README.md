# Unreal Engine AI Prototype

A small Unreal Engine prototype focused on basic AI behavior implemented in Blueprints.

This project demonstrates a simple enemy logic with:
- patrolling between points
- detecting the player
- switching to chase behavior
- returning to patrol when the player is lost

## Tech

- Unreal Engine
- Blueprints

## Purpose

This prototype was created to test and validate a basic AI behavior flow in a clean and practical setup.
